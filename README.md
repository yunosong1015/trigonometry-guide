# 삼각비 가이드 (Trigonometry Guide)

중학교 3학년 「삼각비」 단원 수업용 웹 페이지입니다.
설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있고, **인터넷 연결 없이도 동작**합니다.

## 1. 구성

| 섹션 | 내용 |
|---|---|
| 1. 삼각비란 무엇인가요? | ∠C = 90°인 직각삼각형에서 sin·cos·tan의 뜻 (색으로 구분한 SVG 그림) |
| 2. 크기가 달라져도 비는 같을까요? | 각 A를 고정하고 삼각형 크기만 바꿔 보며, 두 변의 길이의 비가 일정함을 표로 확인 |
| 3. 특수각의 삼각비 | 0°·30°·45°·60°·90° 표 — 칸을 눌러 값 확인, 전체 보기 / 전체 숨기기 |
| 4. 사분원에서 보는 삼각비 | 반지름 1인 사분원에서 세 삼각비를 선분으로 표현. 슬라이더·특수각 버튼으로 조작 |
| 5. 삼각비의 표와 계산기 | 0°~90° 1° 간격 표 + 각도를 입력하면 해당 줄을 찾아 주는 도구 |
| 6. 실생활 활용 | 나무 높이·경사로·사다리 문제 3개 (풀이 접기/펼치기) |

## 2. 수업에서 쓰는 방법

- **색 약속** — sin은 파랑, cos는 주황, tan은 빨강, 빗변은 회색. 1번과 3번 그림이 같은 색을 씁니다.
- **가리고 묻기** — 표의 칸과 값 패널은 처음에 `?`로 가려져 있습니다. 학생에게 먼저 묻고 눌러서 확인하세요.
- **큰 글씨 버튼** — 오른쪽 위 버튼을 누르면 전자칠판·프로젝터용으로 글씨와 그림이 커집니다.
- **인쇄** — 브라우저에서 인쇄하면 조작 버튼은 빠지고 **가려둔 답과 풀이가 모두 펼쳐진** 형태로 출력됩니다. 학습지로 쓸 수 있습니다.
- **키보드** — 표의 칸과 값 패널은 Tab으로 이동해 Enter/Space로 열 수 있습니다.

### 2번 섹션(크기와 비) 수업 흐름 제안

1. 각 A를 30°로 맞춘 뒤 **크기 슬라이더만** 좌우로 움직입니다.
2. "높이·밑변·빗변 숫자는 어떻게 되나요?" → 전부 달라집니다.
3. "그럼 오른쪽 파란 칸(비)은요?" → **세 줄이 모두 같습니다.**
4. 각 A를 45°, 60°로 바꾸면 비의 값이 달라지는 것을 확인 → **비는 크기가 아니라 각으로 정해진다.**
5. 흐리게 그려진 두 삼각형(c=5, c=10)은 항상 함께 보이므로, 세 삼각형이 닮음임을 눈으로 확인할 수 있습니다.

## 3. 지도상 유의점

- `tan 90°`는 **무한대(∞)가 아니라 "정할 수 없다"** 로 표기했습니다. 90°에서는 밑변의 길이가 0이 되어 나눗셈이 성립하지 않기 때문입니다.
- 3번 그림에서 각이 커지면 **세로 눈금이 1.5 → 2 → 3으로 자동으로 넓어집니다.** tan이 커지는 모습을 보여주기 위한 것이며, 화면 아래에 안내 문구가 나옵니다.
- 71° 부근을 넘으면 tan 선분에 화살표가 붙고 "화면을 넘어설 만큼 커졌습니다"라고 표시됩니다.
- 삼각형 표기는 교과서 관례를 따랐습니다. ∠C = 90°, 대변은 각각 a(높이), b(밑변), c(빗변).

## 4. 기술

- HTML5 / Vanilla CSS / Vanilla JS — **외부 라이브러리·CDN을 전혀 쓰지 않습니다.**
- 본문 글꼴은 시스템에 기본 설치된 한글 글꼴(맑은 고딕, Apple SD Gothic Neo 등)을 사용합니다.
- 숫자·수식에는 `fonts/` 폴더의 D2Coding을 로컬로 불러옵니다.
- 사분원 그림은 JavaScript로 SVG를 그립니다.
