## 3. 수업에서 쓰는 방법

- **한 번에 한 활동만** — 상단 메뉴(1~9)를 누르면 그 활동만 화면에 나타납니다. 수업 중 학생이 뒤 내용을 미리 보지 못하게 하려는 구성입니다.
- 각 활동 아래의 **← / → 버튼**으로도 이동할 수 있고, 가운데에 `3 / 9`처럼 진행 위치가 표시됩니다.
- 주소 뒤에 `#trends`처럼 붙이면 **그 활동으로 바로 열립니다.** 브라우저 뒤로 가기도 동작하므로, 특정 활동 링크를 학생에게 따로 공유할 수 있습니다.
- **인쇄할 때는 9개 활동이 모두 출력됩니다.** (가려둔 답과 풀이도 함께 펼쳐집니다.)

- **색 약속** — sin은 파랑, cos는 주황, tan은 빨강, 빗변은 회색. 2·4·5·7번 그림과 표가 모두 같은 색을 씁니다.
- **가리고 묻기** — 표의 칸과 값 패널은 처음에 `?`로 가려져 있습니다. 학생에게 먼저 묻고 눌러서 확인하세요.
- **큰 글씨 버튼** — 오른쪽 위 버튼을 누르면 전자칠판·프로젝터용으로 글씨와 그림이 커집니다.
- **키보드** — 표의 칸과 값 패널은 Tab으로 이동해 Enter/Space로 열 수 있습니다.

### 1번 섹션(복습·도입) 수업 흐름 제안

1. 6개 도형을 보여 주고 "**x를 구할 수 있는 것**을 모두 고르라"고 합니다. (개별/모둠 판단)
2. 카드마다 **구할 수 있다 / 없다** 버튼을 눌러 확인합니다. 상단에 몇 개를 확인했는지 표시됩니다.
3. 6개를 모두 확인하면 아래에 **정리 상자**가 자동으로 나타납니다.
4. 핵심 발문 — "(4)와 (5)에서는 **각의 크기 하나만으로** 빗변의 절반이라는 비를 알 수 있었지요. 그럼 50°는요?"
5. 이 물음을 그대로 2번(에스컬레이터) 섹션으로 가져갑니다.

- `모두 확인하기` : 시간이 없을 때 한 번에 펼칩니다.
- `다시 풀기` : 다음 반 수업을 위해 초기화합니다.

### 2번 섹션(에스컬레이터) 수업 흐름 제안

1. 학습지의 "필요한 그림 그리기 / 높이를 구하는 과정 설명하기" 칸을 **먼저 손으로** 채우게 합니다.
2. 축척 버튼(1 cm = 2 m / 4 m / 5 m)을 눌러 **축척마다 그림이 얼마나 커지는지** 비교합니다.
3. 화면 눈금자로 높이를 읽고 입력 → `잰 값 × 축척 = 실제 높이` 계산 과정이 그대로 보입니다.
4. 축척을 바꿔도 **실제 높이는 같게 나온다**는 점을 확인시킵니다. (닮음의 핵심)
5. ③번에서 "1번 활동의 몇 번과 조건이 같은가"를 고릅니다. 정답은 **(6)** — 한 각의 크기와 한 변의 길이만 주어진 경우.

### 3번 섹션(탈레스) 수업 흐름 제안

1. 탈레스 이야기를 읽고, 두 슬라이더로 그림자 길이를 바꿔 가며 피라미드 높이를 계산해 봅니다.
2. 8개 문장을 **공통점 / 차이점**으로 분류합니다. 모두 분류하면 정리 상자가 나타납니다.
3. 마무리 발문 — "각의 크기만 알면 변의 비를 바로 알 수 있다면 그림을 안 그려도 되지 않을까?" → 4번으로.

### 4번 섹션(탐구) 수업 흐름 제안

1. 각 A를 30°로 맞춘 뒤 **크기 슬라이더만** 좌우로 움직입니다.
2. "높이·밑변·빗변 숫자는 어떻게 되나요?" → 전부 달라집니다.
3. "그럼 오른쪽 파란 칸(비)은요?" → **세 줄이 모두 같습니다.**
4. 각 A를 45°, 60°로 바꾸면 비의 값이 달라지는 것을 확인 → **비는 크기가 아니라 각으로 정해진다.**
5. 흐리게 그려진 두 삼각형(c=5, c=10)은 항상 함께 보이므로, 세 삼각형이 닮음임을 눈으로 확인할 수 있습니다.
6. "이렇게 각으로만 정해지는 값이라면 이름을 붙여 두면 편하겠지요?" → **5번 섹션(삼각비의 정의)으로 넘어갑니다.**

> 1 → 5번의 순서는 의도적입니다. **막힘(1번) → 옛 방법으로 해결(2·3번) → 발견(4번) → 이름 붙이기(5번)** 순으로, 용어(sin·cos·tan)를 마지막에 줍니다. 그래서 4번 표의 열 이름도 `a ÷ c`처럼 비 자체로만 적혀 있습니다.

## 4. 지도상 유의점

- 1번 (6)번 도형은 **일부러 풀리지 않게** 만든 문제입니다. 학생이 막히는 경험을 해야 삼각비의 필요성이 살아나므로, 답을 먼저 알려 주지 마세요.
- `tan 90°`는 **무한대(∞)가 아니라 "정할 수 없다"** 로 표기했습니다. 90°에서는 밑변의 길이가 0이 되어 나눗셈이 성립하지 않기 때문입니다.
- 7번 그림에서 각이 커지면 **세로 눈금이 1.5 → 2 → 3으로 자동으로 넓어집니다.** tan이 커지는 모습을 보여주기 위한 것이며, 화면 아래에 안내 문구가 나옵니다.
- 71° 부근을 넘으면 tan 선분에 화살표가 붙고 "화면을 넘어설 만큼 커졌습니다"라고 표시됩니다.
- 삼각형 표기는 교과서 관례를 따랐습니다. ∠C = 90°, 대변은 각각 a(높이), b(밑변), c(빗변).
